# Кино на вечер

Микросервисная система рекомендаций фильмов на основе готового набора MovieLens Small. Пользователь ищет фильмы, ставит нескольким оценки и получает подборку на вечер.

## Задача и сценарии

Целевой пользователь — зритель, который хочет быстро выбрать фильм по своим предпочтениям. Система поддерживает четыре сценария:

1. Загрузить очередной батч фильмов или оценок из локального источника; для первого запуска доступна загрузка всего набора.
2. Найти фильм по названию и посмотреть жанры.
3. Обучить модель рекомендаций на загруженных оценках и посмотреть её состояние.
4. Оценить несколько фильмов и получить персональную подборку.

MovieLens Small содержит 9 742 фильма и 100 836 оценок. Данные взяты из [официального набора GroupLens](https://grouplens.org/datasets/movielens/latest/). Условия использования приведены в `collector/data/README.txt`. Проект использует только `movies.csv` и `ratings.csv`; персональные данные не загружаются. Дата скачивания: 8 ноября 2026 года.

Источник данных: F. Maxwell Harper и Joseph A. Konstan, *The MovieLens Datasets: History and Context*, ACM TiiS 5(4), 2015, DOI: [10.1145/2827872](https://doi.org/10.1145/2827872). Набор предназначен для исследовательского использования; GroupLens не поддерживает и не одобряет данный проект.

## Архитектура

```text
Браузер → Visualization (8080) → Web Master (8000)
                                    ├→ Collector → CSV + журнал загрузок
                                    ├→ Storage → SQLite
                                    └→ ML Service → файл модели
```

Каждый сервис работает в отдельном контейнере, имеет собственный `Dockerfile`, REST API, JSON-конфигурацию и обработку ошибок. Web Master — единая точка входа для пользовательских сценариев. Collector читает готовый CSV батчами и записывает журнал запросов. Storage выполняет CRUD для фильмов и хранит оценки в SQLite. ML Service обучает модель сходства фильмов по совместным положительным оценкам. При редких совпадениях рекомендации дополняются популярными фильмами близких жанров. Модель хранится в отдельном томе Docker.

Рекомендательная оценка не является вероятностью понравиться фильму. Она служит для сортировки кандидатов. Результаты ограничены качеством и возрастом MovieLens Small, а новые фильмы вне набора отсутствуют.

## Запуск

Требуются Docker и Docker Compose. Из корня репозитория:

```bash
docker compose up --build -d
```

Откройте <http://localhost:8080>. Нажмите «Загрузить MovieLens», затем «Обучить модель». После этого найдите фильмы, оцените несколько и нажмите «Подобрать фильмы». Первый импорт занимает время: Collector выдаёт оценки батчами по 2 000 строк.

Проверка состояния: <http://localhost:8000/status>. Swagger API: <http://localhost:8000/docs>. Остановка: `docker compose down`. Для удаления сохранённых данных и модели: `docker compose down -v`.

## API и конфигурация

| Сервис | Основные методы |
|---|---|
| Collector | `GET /batch/{movies\|ratings}?offset=&limit=`, `GET /summary` |
| Storage | `POST /movies/batch`, `GET /movies`, `GET/PUT/DELETE /movies/{id}`, `POST /ratings`, `GET /ratings/{user_id}`, `GET /export`, `GET /stats` |
| ML Service | `POST /models`, `POST /train`, `POST /recommend`, `GET /summary` |
| Web Master | `POST /import/{kind}`, `POST /import-all`, `GET /movies`, `POST /train`, `POST /recommend`, `GET /status` |
| Visualization | `GET /` |

Параметры лежат в `*/config.json`. URL сервисов задаются переменными окружения в `docker-compose.yml`. SQLite, журнал Collector и файл модели сохраняются в томах Docker.

Пример запроса после импорта и обучения:

```bash
curl -X POST http://localhost:8000/recommend \
  -H 'Content-Type: application/json' \
  -d '{"choices":[{"movieId":1,"rating":5},{"movieId":356,"rating":4.5}],"limit":5}'
```

## Текущий статус и дальнейшая работа

Реализованы пять сервисов, контейнеризация, загрузка данных, поиск, обучение и интерфейс рекомендаций. Планируется проверить качество рекомендаций на отложенных оценках, добавить историю запросов и улучшить объяснения рекомендаций в интерфейсе.
